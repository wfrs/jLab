Plasmid Workflow — UI/UX Render Options

Low-fidelity wireframes to choose interaction style before high-fidelity design.

1) Single-page workspace with panels

Best for power users. Fewer clicks, faster editing loops.
Top Toolbar: Search | New Plasmid | Duplicate | Save | Publish
Plasmid list (filterable)
Core metadata form
GMO entries + status timeline
Cassette composer with token helper
Attachments + GenBank
Validation panel (missing fields, risks, warnings)

2) Step-by-step wizard flow

Best for guided onboarding and fewer data-entry mistakes.
Stepper: 1 Metadata → 2 Cassettes → 3 GMOs → 4 Files → 5 Review
Current Step Form Area (single focus)
Inline help
Progress + completion hints
Context summary (sticky side card)
Back
Save Draft
Next

3) Master-detail split view

Balanced approach for browsing + editing with good context retention.
Header: Search | Filters | New | Bulk actions
Left: Plasmid table/list
Quick stats + badges
Right: Selected plasmid details
Tabs: Core / Cassettes / GMOs
Files / Publish / History

4) Table-first + slide-over editors

Strong for fast list operations and compact desktop workflows.
Toolbar: Search | Filters | Batch actions | Export
Main table (sortable, columns, status chips)
Bulk selection actions
Slide-over editor: details + save/cancel
Inline validation + quick links
