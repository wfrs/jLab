# Documentation

This folder is the documentation root for jlab, the reimplementation of the legacy GMOCU app.

## Structure

- `architecture/`: target architecture documents for the new implementation.
- `decisions/`: architecture decision records (ADRs).
- `plans/`: implementation and migration plans.
- `legacy-analysis/`: reverse-engineered analysis of the legacy GMOCU app.

## Legacy analysis contents

See `legacy-analysis/` for:

- feature inventory
- user workflows
- technology inventory
- architecture diagram
- technical debt assessment
- modernization proposal
- deep dive and code map
